# 版本记录

## V1.0.0

- 发布四个独立工作流，面向 Armbian 设备的能力查询、硬件应用接入、部署和验证。
- 提供共享多平台资料，收录 reComputer RK3576/RK3588 DevKit，包含匹配辅助和可选的设备只读探测。
- 文档和工作流默认英文，提供独立中文版本，以及以 Codex、Claude Code 为例的 SSH 快速上手指南。
- 补齐 RK3588 V1.0 J10 全部40位置、电平路径、局部GPIO偏移和复用/共享限制。J10-23/40同为GPIO2_C0_3V3，不能独立控制；J10-15使用U34 A3/4脚和B3/17脚。
- 每个 Skill 独立打包，包含双语资料、完整性清单、可移植测试和可复现构建。
- 发布静态资料与工作流，不附带开发方案、评估过程、实测报告或设备快照；当前设备就绪状态与应用行为仍需逐任务确认。
