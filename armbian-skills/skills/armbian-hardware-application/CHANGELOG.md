# Changelog

## V1.0.0

- Release four independent workflows for capability discovery, hardware application integration, deployment and verification on Armbian devices.
- Include shared multi-platform references with reComputer RK3576/RK3588 DevKit profiles, matching helpers and optional read-only device probing.
- Provide English-first documentation and workflows with independent Chinese translations, plus an SSH quick start for Codex and Claude Code.
- Cover all 40 RK3588 V1.0 J10 positions, voltage paths, local GPIO offsets, mux candidates and shared resources. J10-23/40 share GPIO2_C0_3V3 and are not independently controllable; J10-15 uses U34 A3/pin4 and B3/pin17.
- Package each Skill independently with both languages, integrity manifests, portable tests and reproducible builds.
- Distribute static references and workflows without development proposals, evaluation history, trial reports or device snapshots. Confirm current target readiness and application behavior per task.
